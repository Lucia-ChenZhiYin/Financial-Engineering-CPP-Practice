04. Forward Rate Calculation

遠期利率計算

利用不同到期期間的零息利率（Zero Rates）， 根據無套利原則推算不同期間之間的遠期利率（Forward Rates）。

01. Overview

Forward Rate 是指兩個未來期間之間隱含的利率。 本程式利用已知的年化零息利率， 透過複利累積因子之間的關係， 計算不同起始期間與結束期間的遠期利率。

本題設定總期間為四年，每半年為一期， 因此共有八期，並使用半年複利進行計算。

02. Input Variables

  • ZeroRate[8]：儲存八期的年化零息利率。
  • Forward[9][9]：儲存不同期間組合的遠期利率。
  • a：遠期利率的起始期間。
  • b：遠期利率的結束期間。
  • Forward[0][b]：儲存第 b 期的 Zero Rate。
  • pow()：計算次方，用於複利累積因子的計算。

03. Source Code

#include <stdio.h>
#include <math.h>

int main()
{
    double ZeroRate[8]; //Zero Rate 數量
    double Forward[9][9];//有八期

    for(int i=0;i<8;i=i+1)  //Input zero rates
    {
        printf("Input the %d-th zero rate:",i+1);
        scanf("%lf",&ZeroRate[i]);
    }

    for(int i=0;i<8;i=i+1)
    {
        Forward[0][i+1]=ZeroRate[i];
    }

    for(int i=0;i<=8;i=i+1)
    {
        Forward[i][i]=0;
    }

    for(int a=1;a<8;a=a+1) //Find forward rates
    {
        for(int b=a+1;b<=8;b=b+1)
        {
            Forward[a][b]=2*(pow(
                pow(1+Forward[0][b]/2,b)
                /pow(1+Forward[0][a]/2,a),
                1.0/(b-a))-1);
        }
    }

    printf("f(0,1)=%.4lf\n",ZeroRate[0]*100);

    for(int i=1;i<8;i=i+1) //Output the forward rates
    {
        printf("f(%d,%d)=%lf\n",i,i+1,Forward[i][i+1]*100);
    }

    return 0;
}
