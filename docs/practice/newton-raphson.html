Newton-Raphson Method

牛頓法｜Bond Internal Rate of Return

01. Overview

本次練習使用牛頓法（Newton-Raphson Method） 求解債券的內部報酬率（Internal Rate of Return, IRR）。 透過函數值與導數，不斷更新利率估計值， 逐步逼近使債券現值等於市場價格的利率。

02. Input Variables

  • C：每期票面利息（Coupon Payment）
  • X：債券市場價格（Bond Price）
  • N：剩餘期數（Number of Periods）
  • rk：目前估計的利率
  • initialr：初始利率，設定為 0.01
  • BondPV：計算出的債券現值
  • f_r：債券現值與市場價格的差額
  • df_r：函數的導數
  • Discount：折現因子

03. Source Code

#include<stdio.h>
#include<math.h>
int main(){
    int N;
    double C,Discount,f_r,X,rk,df_r;
    double BondPV=0,initialr=0.01;
    printf("put C :");
    scanf("%lf",&C);
    printf("put $X :");
    scanf("%lf",&X);
    printf("put N-th:");
    scanf("%d",&N);

    f_r=1;
    rk=initialr;
    while (fabs(f_r)>=0.001){
        BondPV=0;
        df_r=0;
        for(int i=1;i<=N;i++){
            Discount=1;
            for(int j=1;j<=i;j++){
                Discount=Discount/(1+rk);
            }
            BondPV=BondPV+Discount*C;
            df_r=df_r-(Discount/(1+rk))*i*C;
            if(i==N){
                BondPV=BondPV+Discount*100;
                df_r=df_r-(Discount/(1+rk))*N*100;
            }
        }
        f_r=BondPV-X;
        rk=rk-(f_r/df_r);
    }
    printf("IRR_Newton=%lf\n",rk);
    return 0;
}
