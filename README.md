# Financial Engineering – C++ Practice

這個 Repository 用來保存我在 **「財務工程導論」課程**中所練習與學習的 C++ 程式，記錄課堂範例、實作練習以及程式設計過程中的學習歷程。

透過實際撰寫、編譯與執行程式，逐步熟悉 C++ 語法，並將程式應用於財務工程相關的計算與問題。

## 📚 Project Purpose

- 整理財務工程導論課程中的 C++ 程式練習。
- 保存課堂範例與個人實作紀錄。
- 記錄程式語法、運算邏輯及相關財務概念。
- 透過反覆練習，培養程式撰寫與問題解決能力。

## 💻 Development Environment

- **Programming Language:** C++
- **IDE:** Visual Studio Code
- **Compiler:** GCC / G++ (MSYS2)
- **Operating System:** Windows

## 📂 Repository Contents

依照課程進度與練習主題，逐步整理程式碼、學習筆記及相關紀錄。

## 🌱 Future Plans

完成課程程式與筆記的整理後，計畫進一步使用 **HTML、CSS** 製作個人學習展示網站，將這份練習集轉化為更完整的數位學習作品集。

預計網站將包含：

- **Practice Collection：** 展示各單元的 C++ 程式練習。
- **Learning Journey：** 記錄課程學習過程與程式能力的累積。
- **Study Notes：** 整理重要語法、程式邏輯及財務工程相關知識。
- **Project Showcase：** 展示具有代表性的程式實作與成果。

## 🎯 Learning Goal

希望透過這份練習集，不只是保存完成過的程式，更能持續記錄自己從課堂學習、實際操作到獨立理解程式邏輯的過程，並逐步建立一份能夠展示學習成果的個人作品集。
