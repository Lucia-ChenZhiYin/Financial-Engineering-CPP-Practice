04. Forward Rate Calculation

遠期利率計算

利用不同到期期間的年化零息利率（Zero Rates）， 透過無套利關係推算不同期間之間的遠期利率（Forward Rates）。

01. Overview

Forward Rate 是指從未來某個時間點開始， 到另一個未來時間點之間的隱含利率。 本程式以四年為期間，每半年為一期， 將八期 Zero Rates 作為輸入， 並利用無套利原則計算各期間的 Forward Rates。

02. Input Variables

  • ZeroRate[8]：儲存八期年化零息利率。
  • Forward[9][9]：儲存不同起始與結束期間的遠期利率。
  • a：遠期利率的起始期間。
  • b：遠期利率的結束期間。
  • 1.0/(b-a)：將整段期間的累積報酬換算為每期報酬。
  • pow()：計算次方，用於複利累積與期間換算。

注意：程式輸入利率時使用小數格式， 例如 1.20850% 應輸入 0.012085。 輸出時再乘以 100 轉換成百分比。

03. Source Code

#include <stdio.h>
#include <math.h>

int main()
{
    double ZeroRate[8]; // Zero Rate 數量
    double Forward[9][9]; // 有八期

    // Input zero rates
    for(int i=0;i<8;i=i+1)
    {
        printf("Input the %d-th zero rate:",i+1);
        scanf("%lf",&ZeroRate[i]);
    }

    // Store zero rates in the first row
    for(int i=0;i<8;i=i+1)
    {
        Forward[0][i+1]=ZeroRate[i];
    }

    // Set diagonal values to zero
    for(int i=0;i<=8;i=i+1)
    {
        Forward[i][i]=0;
    }

    // Find forward rates
    for(int a=1;a<8;a=a+1)
    {
        for(int b=a+1;b<=8;b=b+1)
        {
            Forward[a][b]=2*(
                pow(
                    pow(1+Forward[0][b]/2,b)
                    /pow(1+Forward[0][a]/2,a),
                    1.0/(b-a)
                )-1
            );
        }
    }

    // Output forward rates
    printf("f(0,1)=%.4lf\n",ZeroRate[0]*100);

    for(int i=1;i<8;i=i+1)
    {
        printf("f(%d,%d)=%lf\n",
               i,i+1,Forward[i][i+1]*100);
    }

    return 0;
}
