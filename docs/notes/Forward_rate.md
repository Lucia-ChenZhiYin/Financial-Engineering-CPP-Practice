# Forward Rate Calculation（遠期利率計算）

## 1. 核心概念（Core Idea）

Forward Rate（遠期利率）是指從未來某個時間點開始，到另一個未來時間點之間的隱含利率。

本題設定：

- 投資期間：4 年。
- 每期期間：6 個月。
- 每年有 2 期，因此總共分成 8 期。
- 已知 8 個不同到期期間的年化零息利率（Annual Zero Rates）。
- 利用已知的 Zero Rates，計算不同期間之間的 Forward Rates。

### Zero Rate 與 Forward Rate 的差異

**Zero Rate（零息利率）**

代表從現在開始投資，到某個指定到期期間的利率。

例如：

- Z1：從現在投資到第 1 期的零息利率。
- Z2：從現在投資到第 2 期的零息利率。
- Z3：從現在投資到第 3 期的零息利率。

**Forward Rate（遠期利率）**

代表從某個未來期間開始，到另一個未來期間之間的利率。

例如：

- f(0,1)：從現在到第 1 期的利率。
- f(1,2)：從第 1 期到第 2 期的遠期利率。
- f(1,3)：從第 1 期到第 3 期的遠期利率。
- f(2,5)：從第 2 期到第 5 期的遠期利率。

簡單來說：

- Zero Rate：從現在投資到未來。
- Forward Rate：未來某個期間到另一個未來期間。

---

## 2. 無套利原則（No-Arbitrage Principle）

為什麼只知道不同到期期間的 Zero Rates，就能計算 Forward Rates？

關鍵在於無套利原則。

假設今天有 100 元，可以選擇兩種投資方式：

### 選擇 A：直接投資到第 2 期

利用第 2 期的 Zero Rate（Z2），直接投資兩個半年期。

最後的累積金額：

`100 × (1+Z2/2)^2`

### 選擇 B：分成兩段投資

先利用第 1 期的 Zero Rate（Z1）投資一個半年期，再利用 f(1,2) 投資下一個半年期。

最後的累積金額：

`100 × (1+Z1/2) × (1+f(1,2)/2)`

### 為什麼兩者必須相等？

兩種方式都是從同一個時間點開始投資，並且在第 2 期結束。

在無套利條件下，如果兩種投資方式的最終金額不同，投資人就可以選擇報酬較高的方式，造成套利機會。

因此，兩種方式的累積金額必須相等：

`100 × (1+Z2/2)^2`

`= 100 × (1+Z1/2) × (1+f(1,2)/2)`

這就是推導 Forward Rate 的基礎。

---

## 3. Forward Rate 公式推導

我們先從相鄰的兩期開始推導。

### Step 1：建立等式

由無套利原則：

`(1+Z2/2)^2 = (1+Z1/2) × (1+f(1,2)/2)`

### Step 2：將 Forward Rate 留在等式的一邊

兩邊同時除以 `(1+Z1/2)`：

`1+f(1,2)/2 = (1+Z2/2)^2 / (1+Z1/2)`

### Step 3：整理出 Forward Rate

兩邊乘以 2，再移項：

`f(1,2) = 2 × [(1+Z2/2)^2 / (1+Z1/2) - 1]`

這就是兩個相鄰半年期之間的遠期利率公式。

### 一般化公式

如果要計算從第 a 期到第 b 期的 Forward Rate：

- a：起始期間。
- b：結束期間。
- Za：到第 a 期的年化零息利率。
- Zb：到第 b 期的年化零息利率。
- b-a：兩個期間之間相隔的期數。

直接投資到第 b 期：

`(1+Zb/2)^b`

先投資到第 a 期，再從第 a 期投資到第 b 期：

`(1+Za/2)^a × (1+f(a,b)/2)^(b-a)`

根據無套利原則：

`(1+Zb/2)^b`

`= (1+Za/2)^a × (1+f(a,b)/2)^(b-a)`

整理後得到：

`f(a,b) = 2 × [((1+Zb/2)^b / (1+Za/2)^a)^(1/(b-a)) - 1]`

這就是本題程式使用的公式。

---

## 4. 為什麼公式要除以 2、乘以 2？

這題的投資期間是每半年一期，因此一年有兩期。

但題目提供的 Zero Rates 是年化利率，所以需要將年化利率轉換成半年期利率。

### 年化利率轉換成半年期利率

例如年化利率為 2%：

`2% / 2 = 1%`

因此，每半年期的利率為 1%。

### 半年期利率轉換成年化報價

程式最後將半年期計算出的利率乘以 2，轉換成年化報價。

因此公式中：

- `/2`：將年化利率轉換為半年期利率。
- `×2`：將半年期利率轉回年化報價。

這是本題採用的半年複利及年化報價方式。

## 5. 程式架構與變數說明

### 主要變數

| 變數 | 用途 |
|---|---|
| `ZeroRate[8]` | 儲存八期年化零息利率 |
| `Forward[9][9]` | 儲存不同起始與結束期間的利率資料 |
| `a` | 遠期利率的起始期間 |
| `b` | 遠期利率的結束期間 |
| `i` | 迴圈計數器 |

### Step (a)：輸入 Zero Rates

```cpp
for(int i=0;i<8;i=i+1)
{
    printf("Input the %d-th zero rate:",i+1);
    scanf("%lf",&ZeroRate[i]);
}
```

使用迴圈輸入八期零息利率，並存入一維陣列 `ZeroRate`。

注意：輸入時使用小數格式。

例如：

`1.20850% = 0.012085`

### Step (b)：將 Zero Rates 放入矩陣第一列

```cpp
for(int i=0;i<8;i=i+1)
{
    Forward[0][i+1]=ZeroRate[i];
}
```

將八期 Zero Rates 存放在 `Forward` 矩陣的第一列。

例如：

- `Forward[0][1]`：第一期 Zero Rate。
- `Forward[0][2]`：第二期 Zero Rate。
- `Forward[0][8]`：第八期 Zero Rate。

這樣後續計算就能透過矩陣索引取得不同期間的零息利率。

### Step (c)：設定矩陣對角線

```cpp
for(int i=0;i<=8;i=i+1)
{
    Forward[i][i]=0;
}
```

將矩陣對角線設為 0。

因為起始期間與結束期間相同時，兩者之間沒有經過任何時間，因此沒有期間利率需要計算。

### Step (d)：計算 Forward Rates

```cpp
for(int a=1;a<8;a=a+1)
{
    for(int b=a+1;b<=8;b=b+1)
    {
        Forward[a][b]=2*(
            pow(
                pow(1+Forward[0][b]/2,b)
                /pow(1+Forward[0][a]/2,a),
                1.0/(b-a)
            )-1
        );
    }
}
```

這是整份程式最重要的部分。

**外層迴圈 a：**

設定遠期利率的起始期間。

從第 1 期開始，逐步改變起始期間。

**內層迴圈 b：**

設定遠期利率的結束期間。

結束期間必須大於起始期間，因此：

`b = a+1, a+2, ... , 8`

兩層迴圈搭配後，就能計算不同起始與結束期間的 Forward Rates。

### 公式與程式碼對照

| 程式碼 | 數學意義 |
|---|---|
| `Forward[0][b]` | 第 b 期 Zero Rate |
| `Forward[0][a]` | 第 a 期 Zero Rate |
| `pow(1+.../2,b)` | 投資到第 b 期的累積因子 |
| `pow(1+.../2,a)` | 投資到第 a 期的累積因子 |
| `1.0/(b-a)` | 換算成每期的累積報酬 |
| `*2` | 轉換成年化利率報價 |

### Step (e)：輸出結果

```cpp
printf("f(0,1)=%.4lf\n",ZeroRate[0]*100);

for(int i=1;i<8;i=i+1)
{
    printf("f(%d,%d)=%lf\n",
           i,i+1,Forward[i][i+1]*100);
}
```

第一個輸出直接將第一期 Zero Rate 當作 `f(0,1)`。

後面的迴圈則輸出相鄰期間的 Forward Rates：

- f(1,2)
- f(2,3)
- f(3,4)
- f(4,5)
- f(5,6)
- f(6,7)
- f(7,8)

注意：前面的雙層迴圈其實計算了所有 `a < b` 的組合，但這裡只輸出相鄰期間的結果。

## 6. 程式執行流程

整份程式可以整理成以下順序：

1. 建立 `ZeroRate[8]` 與 `Forward[9][9]`。
2. 輸入八期年化 Zero Rates。
3. 將 Zero Rates 放入 Forward 矩陣第一列。
4. 將矩陣對角線設定為 0。
5. 使用雙層迴圈設定起始期間 a 與結束期間 b。
6. 根據無套利公式計算 Forward Rate。
7. 輸出 f(0,1) 與各相鄰期間的 Forward Rates。

### 為什麼使用二維陣列？

因為 Forward Rate 同時受到兩個時間點影響：

- 從哪一期開始？
- 到哪一期結束？

所以使用 `Forward[a][b]`，可以清楚表示從第 a 期到第 b 期的遠期利率。

例如：

`Forward[2][5]`

代表從第 2 期到第 5 期的 Forward Rate。

### 本題的重要觀念

1. Zero Rate 與 Forward Rate 的差異。
2. 無套利原則如何建立兩種投資方式的等式。
3. 如何從累積報酬推導 Forward Rate 公式。
4. 半年複利下，年化利率與半年期利率的轉換。
5. 使用二維陣列儲存不同期間的遠期利率。
6. 使用雙層迴圈自動計算多組 Forward Rates。

### 程式上的注意事項

- 輸入利率必須使用小數，例如 1.20850% 輸入為 0.012085。
- 輸出時乘以 100，才會顯示百分比。
- `Forward[0][1]` 到 `Forward[0][8]` 存放的是 Zero Rates。
- 雙層迴圈只計算 `a < b` 的期間組合。
- 目前輸出區塊只列出相鄰期間的 Forward Rates，並沒有列出所有組合。
