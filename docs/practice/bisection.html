Bisection Method

二分法｜Bond Internal Rate of Return

01. Overview

本次練習使用二分法（Bisection Method） 求解債券的內部報酬率（Internal Rate of Return, IRR）。 透過不斷縮小搜尋區間，逐步逼近使債券現值等於市場價格的利率。

02. Input Variables

  • C：每期票面利息（Coupon Payment）
  • X：債券市場價格（Bond Price）
  • N：剩餘期數（Number of Periods）
  • Low / High：搜尋利率的上下界
  • middle：目前搜尋區間的中點

03. Source Code


#include <stdio.h>

int main(){
    float C,X,Discount,f_r;
    float Low=0,High=1;
    int N;

    printf("$C:");
    scanf("%f",&C);

    printf("$X:");
    scanf("%f",&X);

    printf("N-th:");
    scanf("%d",&N);

    while (High-Low>=0.0001){
        float middle=(High+Low)/2,BondPV=0;

        for(int i=1;i<=N;i++){
            Discount=1;

            for(int j=1;j<=i;j++){
                Discount=Discount/(1+middle);
            }

            BondPV=BondPV+Discount*C;

            if(i==N){
                BondPV=BondPV+Discount*100;
            }
        }

        f_r=BondPV-X;

        if(f_r>0){
            Low=middle;
        }
        else{
            High=middle;
        }
    }

    printf("IRR_Bisection=%8.4f",High);

    return 0;
}

05. Algorithm Steps

  • Step 1：設定搜尋範圍 Low = 0、High = 1。
  • Step 2：計算中間值 middle = (Low + High) / 2。
  • Step 3：利用 middle 計算債券現值 BondPV。
  • Step 4：比較 BondPV 與市場價格 X。
  • Step 5：依照差異調整 Low 或 High。
  • Step 6：重複以上步驟，直到搜尋範圍足夠小。

判斷方式：

  • f_r > 0：現值太高，提高利率，Low = middle。
  • f_r < 0：現值太低，降低利率，High = middle。

06. Learning Notes

本次練習主要熟悉二分搜尋法的應用， 並透過巢狀 for 迴圈計算債券各期現金流的折現價值。 利用 while 迴圈持續縮小利率區間， 直到搜尋精度達到設定條件。
