03. Bootstrapping

拔靴法（零息利率曲線建構）

利用不同到期期間的債券殖利率， 逐期反推出各期間的零息利率， 進而建立 Zero Curve。

01. Overview

Bootstrapping 是一種逐期推算零息利率的方法。 從第一期的殖利率開始，利用已知的短期零息利率， 逐步計算出後續各期的 Zero Rate。

02. Input Variables

  • C：債券每期支付的票面利息。
  • Yield[i]：第 i 期債券的殖利率。
  • ZeroRate[i]：第 i 期的零息利率。
  • BondValue：使用該期殖利率計算的債券價格。
  • sumPV：前面各期利息，以零息利率折現後的總現值。
  • Discount：折現因子。
  • PV：單期利息的現值。

03. Source Code

#include <stdio.h>
#include <math.h>

int main(){
    double ZeroRate[5];
    double Yield[5];
    double C;

    printf("輸入債券每期複習C:");
    scanf("%lf",&C);

    for(int i=0;i<5;i++){
        printf("輸入 i-th 期殖利率 %d :",i+1);
        scanf("%lf",&Yield[i]);
    }

    ZeroRate[0]=Yield[0];

    for(int i=1;i<=4;i++){
        //step(a)
        double BondValue=0;

        for(int j=0;j<=i;j++){
            double Discount=1;

            for(int k=0;k<=j;k++){
                Discount=Discount/(1+Yield[i]);
            }

            BondValue=BondValue+Discount*C;

            if(j==i){
                BondValue=BondValue+Discount*100;
            }
        }

        //Step(b)
        double sumPV = 0;

        for(int j=0;j<i;j++){
            double PV=C;

            for(int k=0;k<=j;k++){
                PV=PV/(1+ZeroRate[i]);
            }

            sumPV = sumPV+PV;
        }

        //Step(c)&(d)
        ZeroRate[i]=pow((C+100)/(BondValue-sumPV),1.0/(i+1))-1;
    }

    for(int i=0;i<=4;i++){
        printf("第 %d 期的零息利率 = %lf",i,ZeroRate[i]);
    }

    return 0;
}
