# Newton-Raphson Method（牛頓法）

## 1. 核心概念

牛頓法（Newton-Raphson Method）是一種數值求解方法。

與二分法不同，牛頓法不是不斷縮小搜尋區間，而是利用目前的估計值與函數的導數，計算下一次更接近答案的位置。

本次練習使用牛頓法求解債券的內部報酬率（Internal Rate of Return, IRR）。

**最重要的想法：先猜一個利率，再利用函數值與斜率修正答案，不斷重複直到誤差足夠小。**

---

## 2. 我們要解決什麼問題？

這題的目標是找到一個利率 r，使債券現值等於市場價格。

債券現值公式：

PV(r) = C/(1+r) + C/(1+r)^2 + ... + (C+100)/(1+r)^N

其中：

- C：每期票面利息
- r：我們想要求出的利率
- N：剩餘期數
- 100：債券到期時償還的本金
- X：債券市場價格

為了方便使用牛頓法，我們將問題整理成：

**f(r) = PV(r) - X**

我們希望找到：

**f(r) = 0**

也就是債券現值與市場價格之間的差額等於零。

---

## 3. 牛頓法的核心公式

牛頓法使用以下公式更新利率：

**r(k+1) = r(k) - f(r(k)) / f'(r(k))**

先不用急著背公式，我們把它拆開：

- r(k)：目前猜測的利率
- f(r(k))：目前利率所產生的價格誤差
- f'(r(k))：目前函數在這個利率位置的斜率
- r(k+1)：修正後的新利率

**公式的想法：**

目前的答案有誤差，我們利用斜率判斷應該修正多少，得到下一次的利率估計值。

重複這個過程，讓誤差逐漸接近零。

---

## 4. 程式中的重要變數

| 程式變數 | 代表意義 |
|---|---|
| rk | 目前估計的利率 |
| initialr | 初始利率，設定為 0.01 |
| BondPV | 目前計算出的債券現值 |
| f_r | 債券現值與市場價格的差額 |
| df_r | 函數的導數，也就是斜率 |
| Discount | 每一期的折現因子 |
| C | 每期票面利息 |
| X | 債券市場價格 |
| N | 剩餘期數 |

特別注意：

- f_r 負責告訴我們目前價格差多少。
- df_r 負責提供函數的斜率。
- rk 負責保存每次更新後的利率。

---

## 5. 程式執行步驟

### Step 1：設定初始利率

```cpp
double BondPV=0,initialr=0.01;

f_r=1;
rk=initialr;
```

一開始我們不知道真正的利率，因此先設定一個初始猜測值。

- initialr = 0.01：初始利率為 1%。
- rk = initialr：將初始猜測值交給 rk。
- f_r = 1：先設定一個非零的初始誤差，讓 while 迴圈可以開始執行。

### Step 2：判斷是否繼續計算

```cpp
while (fabs(f_r)>=0.001){
```

fabs() 是取絕對值的函數。

這裡代表：

只要目前的價格誤差絕對值仍然大於或等於 0.001，就繼續計算。

當誤差小於 0.001 時，就停止迴圈。

### Step 3：重新計算現值與導數

```cpp
BondPV=0;
df_r=0;
```

每次進入新一輪計算，都要先把兩個累加變數歸零。

- BondPV：重新累加債券現值。
- df_r：重新累加函數導數。

避免把上一輪的結果帶進下一輪。

### Step 4：計算每一期的折現價值

```cpp
for(int i=1;i<=N;i++){
    Discount=1;

    for(int j=1;j<=i;j++){
        Discount=Discount/(1+rk);
    }

    BondPV=BondPV+Discount*C;
}
```

這裡使用兩層 for 迴圈。

外層 i：代表目前計算到第幾期。

內層 j：重複除以 (1+rk)，計算該期的折現因子。

最後：

Discount * C

就是該期票面利息折現後的現值。

將每一期的現值累加，就能得到債券票息的現值總和。

### Step 5：計算函數的導數

```cpp
df_r=df_r-(Discount/(1+rk))*i*C;
```

這一行是牛頓法比較重要、也比較容易不理解的地方。

我們已經知道：

- BondPV 計算債券現值。
- f_r 計算債券現值與市場價格的差額。

而 df_r 則是在計算這個函數對利率 r 的導數。

導數可以理解為：當利率改變時，債券現值會如何變化。

因為利率提高時，折現後的債券現值會降低，所以導數為負值。

程式中的：

Discount/(1+rk)

相當於該期折現因子的導數所使用的部分。

再乘上 i*C，就得到該期票息對導數的貢獻。

### Step 6：加入到期本金

```cpp
if(i==N){
    BondPV=BondPV+Discount*100;
    df_r=df_r-(Discount/(1+rk))*N*100;
}
```

當計算到最後一期時，除了票面利息 C，還必須加入到期償還的本金 100。

因此：

- BondPV 加入本金折現後的現值。
- df_r 加入本金對導數的影響。

### Step 7：計算目前的價格誤差

```cpp
f_r=BondPV-X;
```

現在已經算出債券現值 BondPV。

將它減去市場價格 X，就得到目前的價格誤差。

**f_r = 債券現值 - 市場價格**

如果 f_r 不等於零，就代表目前的利率還不是我們要找的答案。

### Step 8：更新利率

```cpp
rk=rk-(f_r/df_r);
```

這是整個牛頓法最核心的一行。

將目前的利率 rk，減去：

f_r / df_r

就能得到下一次的利率估計值。

更新後，程式會回到 while 迴圈，重新計算債券現值與導數。

直到誤差達到設定條件，才停止計算。

---

## 6. 考試時如何回想整份程式？

如果考試時忘記牛頓法的程式怎麼寫，可以按照以下順序回想：

1. **設定初始值**：先猜一個利率 rk。
2. **設定 while**：誤差還不夠小，就繼續計算。
3. **清空累加值**：BondPV 和 df_r 歸零。
4. **計算每期現值**：使用巢狀 for 迴圈。
5. **計算導數**：同步累加 df_r。
6. **加入到期本金**：最後一期加入本金 100。
7. **計算誤差**：f_r = BondPV - X。
8. **更新利率**：使用牛頓法公式更新 rk。
9. **重複計算**：直到誤差小於設定值。

**記憶重點：初始猜測 → 計算現值與導數 → 計算誤差 → 更新利率 → 重複逼近。**

---

## 7. 與二分法的差異

| 比較項目 | 二分法 | 牛頓法 |
|---|---|---|
| 核心概念 | 不斷縮小搜尋區間 | 利用導數修正答案 |
| 主要變數 | Low、High、middle | rk、f_r、df_r |
| 初始設定 | 設定搜尋上下界 | 設定初始利率 |
| 更新方式 | 保留可能包含答案的一半區間 | 計算下一次利率 |
| 主要迴圈 | while | while |
| 共同目標 | 找到使 f(r) = 0 的利率 | 找到使 f(r) = 0 的利率 |
