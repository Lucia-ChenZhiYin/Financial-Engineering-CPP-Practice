Bootstrapping Method

拔靴法｜Zero-Coupon Yield Curve Construction

01. Overview

本次練習使用拔靴法（Bootstrapping Method） 建構零息利率曲線（Zero-Coupon Yield Curve）。 透過已知的債券殖利率與票面利息， 逐期推導不同到期期限所對應的零息利率。

拔靴法的核心概念是利用已經求得的短期零息利率， 進一步計算較長期的零息利率， 逐步完成整條利率曲線。

02. Mathematical Concept

零息利率（Zero Rate）代表特定到期期限下， 單一未來現金流所適用的折現利率。

Bond Pricing Concept

Bond Value = PV(Coupon Payments) + PV(Principal)

拔靴法利用已知的債券價格與殖利率， 先計算債券現值，再扣除已知期間的票息現值， 推導尚未求出的零息利率。

Zero Rate Calculation

ZeroRate[i] = pow(
    (C + 100) / (BondValue - sumPV),
    1.0 / (i + 1)
) - 1;

其中 BondValue 為債券現值， sumPV 為已知期間票息的折現現值， 剩餘部分則用來推導目前到期期限的零息利率。

03. Input Variables

  • C：每期票面利息（Coupon Payment）
  • Yield：各期債券殖利率
  • ZeroRate：各期零息利率
  • BondValue：依殖利率計算的債券現值
  • Discount：折現因子（Discount Factor）
  • sumPV：已知票息的折現現值總和
  • PV：單期票息的折現現值
  • i、j、k：用於控制不同期數的迴圈變數

04. Calculation Process

Step 1. Initialize

輸入每期票面利息及五期殖利率， 並將第一期零息利率設定為第一期殖利率。 

ZeroRate[0] = Yield[0];

Step 2. Calculate Bond Value

利用各期殖利率計算債券現值， 包含每期票息與最後一期的本金。

Step 3. Calculate Known Present Value

計算前面已知期間的票息現值， 作為推導下一期零息利率的基礎。

Step 4. Calculate Zero Rate

利用債券現值扣除已知票息現值， 推導目前期限的零息利率。

Step 5. Repeat

重複以上步驟，直到完成五期零息利率的計算。

05. Source Code

#include <stdio.h>
#include <math.h>

int main(){
    double ZeroRate[5];
    double Yield[5];
    double C;

    printf("輸入債券每期複習C:");
    scanf("%lf",&C);

    for(int i=0;i<5;i++){
        printf("輸入 i-th 期殖利率 %d :",i+1);
        scanf("%lf",&Yield[i]);
    }

    ZeroRate[0]=Yield[0];

    for(int i=1;i<=4;i++){

        // Step(a)
        double BondValue=0;

        for(int j=0;j<=i;j++){
            double Discount=1;

            for(int k=0;k<=j;k++){
                Discount=Discount/(1+Yield[i]);
            }

            BondValue=BondValue+Discount*C;

            if(j==i){
                BondValue=BondValue+Discount*100;
            }
        }

        // Step(b)
        double sumPV = 0;

        for(int j=0;j<i;j++){
            double PV=C;

            for(int k=0;k<=j;k++){
                PV=PV/(1+ZeroRate[i]);
            }

            sumPV = sumPV+PV;
        }

        // Step(c)&(d)
        ZeroRate[i]=pow(
            (C+100)/(BondValue-sumPV),
            1.0/(i+1)
        )-1;
    }

    for(int i=0;i<=4;i++){
        printf("第 %d 期的零息利率 = %lf",i,ZeroRate[i]);
    }

    return 0;
}

06. Learning Notes

本次練習透過巢狀 for 迴圈計算不同期間的債券現值， 並使用陣列保存逐期推導的零息利率。

與二分法及牛頓法不同， 拔靴法主要應用於零息利率曲線的建構， 需要依照到期期限逐步計算， 並利用前面已知的利率資訊推導後續期限。

透過這次練習，可以進一步理解債券定價、 現金流折現以及零息利率之間的關係。
