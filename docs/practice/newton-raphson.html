Newton-Raphson Method

牛頓法｜Bond Internal Rate of Return

01. Overview

本次練習使用牛頓法（Newton-Raphson Method） 求解債券的內部報酬率（Internal Rate of Return, IRR）。 透過函數值與導數，反覆修正利率估計值， 直到計算結果達到設定的收斂精度。

02. Mathematical Concept

牛頓法是一種利用函數導數尋找方程式根的方法。 其基本迭代公式如下：

Newton-Raphson Formula 

r(k+1) = r(k) - f(r(k)) / f'(r(k))

在本次債券 IRR 問題中：

  • f(r) = BondPV - X
  • BondPV：債券現金流折現後的總現值
  • X：債券市場價格
  • f'(r)：債券現值函數對利率的導數
  • r(k)：第 k 次迭代的利率估計值

透過不斷更新利率估計值，使 f(r) 逐漸接近 0。

03. Input Variables

  • C：每期票面利息（Coupon Payment）
  • X：債券市場價格（Bond Price）
  • N：剩餘期數（Number of Periods）
  • rk：目前的利率估計值
  • BondPV：債券現值
  • f_r：現值與市場價格的差額
  • df_r：現值函數對利率的導數
  • initialr：初始利率估計值

04. Source Code

#include <stdio.h>
#include <math.h>

int main(){
    int N;
    double C,Discount,f_r,X,rk,df_r;
    double BondPV=0,initialr=0.01;

    printf("put C :");
    scanf("%lf",&C);

    printf("put $X :");
    scanf("%lf",&X);

    printf("put N-th:");
    scanf("%d",&N);

    f_r=1;
    rk=initialr;

    while (fabs(f_r)>=0.001){
        BondPV=0;
        df_r=0;

        for(int i=1;i<=N;i++){
            Discount=1;

            for(int j=1;j<=i;j++){
                Discount=Discount/(1+rk);
            }

            BondPV=BondPV+Discount*C;
            df_r=df_r-(Discount/(1+rk))*i*C;

            if(i==N){
                BondPV=BondPV+Discount*100;
                df_r=df_r-(Discount/(1+rk))*N*100;
            }
        }

        f_r=BondPV-X;
        rk=rk-(f_r/df_r);
    }

    printf("IRR_Newton=%lf\n",rk);

    return 0;
}

05. Learning Notes

本次練習使用牛頓法求解債券內部報酬率， 透過 BondPV 計算債券現值， 並利用 df_r 計算現值函數的導數。

與二分法相比，牛頓法不需要持續縮小搜尋區間， 而是利用導數修正目前的利率估計值。 因此初始估計值與導數計算會影響迭代結果。
