# Bisection Method（二分法）

## 1. 核心概念

二分法（Bisection Method）是一種數值求解方法。

當我們不知道某個方程式的答案時，可以先設定一個搜尋範圍，再不斷將範圍切成兩半，逐步縮小答案可能出現的位置。

本次練習使用二分法求解債券的內部報酬率（Internal Rate of Return, IRR）。

**最重要的想法：先找到答案的範圍，再不斷縮小範圍。**

---

## 2. 為什麼可以使用二分法？

這題的目標是找到一個利率 \(r\)，使債券的現值等於市場價格。

**債券現值公式：**

PV(r) = C/(1+r) + C/(1+r)^2 + ... + (C+100)/(1+r)^N
其中：

- \(C\)：每期票面利息
- \(N\)：剩餘期數
- \(100\)：債券面額
- \(r\)：我們想要求出的利率

因為債券市場價格為 \(X\)，所以：

\[
PV(r)=X
\]

移項後：

\[
f(r)=PV(r)-X=0
\]

**這就是二分法要尋找的答案：讓 \(f(r)\) 越來越接近 0 的利率。**

### 重要觀念：利率與債券現值的關係

在本題的正現金流條件下：

- 利率越高，未來現金流折現後的現值越低。
- 利率越低，未來現金流折現後的現值越高。

因此，我們可以利用現值與市場價格的差異，判斷利率應該往哪個方向調整。

---

## 3. 二分法的推理步驟

這是本次程式最重要的部分，建議記住以下五個步驟。

### Step 1：設定搜尋範圍

```cpp
float Low=0, High=1;
```

先假設答案的利率介於 0 到 1 之間，也就是 0% 到 100%。

Low 是利率下界，High 是利率上界。

### Step 2：找出中間值

```cpp
float middle=(High+Low)/2;
```

將目前的搜尋範圍切成兩半。

例如：

- Low = 0
- High = 1
- middle = 0.5

接下來先測試 50% 的利率。

### Step 3：計算目前利率下的債券現值

```cpp
BondPV=BondPV+Discount*C;
```

利用目前的 middle 計算每一期現金流的折現價值。

最後一期還要加上債券面額 100。

計算完成後：

```cpp
f_r=BondPV-X;
```

比較計算出來的債券現值與市場價格。

### Step 4：判斷答案應該往哪個方向

這是二分法最重要的判斷。

| 判斷結果 | 代表意義 | 調整方式 |
|---|---|---|
| f_r > 0 | 現值大於市場價格，利率太低 | Low = middle |
| f_r < 0 | 現值小於市場價格，利率太高 | High = middle |

為什麼？

因為利率提高，債券現值會下降。

所以：
- 如果現值太高，就要提高利率。
- 如果現值太低，就要降低利率。

### Step 5：重複搜尋直到足夠接近答案

```cpp
while (High-Low>=0.0001)
```

只要上下界的差距還大於或等於 0.0001，就繼續重複計算。

當區間小於 0.0001 時，停止搜尋，輸出最後的 High。

這就是無限逼近的概念：每一次都縮小搜尋範圍，讓答案越來越精確。

---

## 4. 程式架構記憶

如果未來要自己重新寫一次二分法，可以先記住這個架構：

1. **輸入資料**：取得 C、X、N。
2. **設定範圍**：Low = 0、High = 1。
3. **開始搜尋**：使用 while 判斷搜尋範圍是否足夠小。
4. **計算中點**：middle = (Low + High) / 2。
5. **計算現值**：使用 for 迴圈計算每期折現現金流。
6. **比較差異**：f(r) = BondPV - X。
7. **更新範圍**：依照 f(r) 正負調整 Low 或 High。
8. **輸出結果**：停止搜尋後輸出利率。

### 記憶口訣

**輸入 → 設範圍 → 找中點 → 算現值 → 做比較 → 縮範圍 → 輸出答案**

---

## 5. 這次練習需要理解的重點

- 二分法不是直接算出答案，而是透過反覆縮小範圍找到近似解。
- middle 是目前測試的利率。
- BondPV 是使用 middle 計算出來的債券現值。
- f_r 用來判斷目前利率太高還是太低。
- while 負責控制搜尋何時停止。
- 0.0001 是本程式設定的搜尋區間精度。
